## DATABASE

Create a file: `supabase/schema.sql`
This file must contain ready-to-run SQL that the developer pastes into
Supabase SQL Editor and executes. Include:
- CREATE TABLE statements for all tables below
- Enable RLS but add permissive policies so anon can read,
  and service_role can do full CRUD
- Add comments explaining each table

Table: categories
- id uuid PK default gen_random_uuid()
- name_bg text not null
- name_en text not null
- image_url text
- sort_order int default 0
- created_at timestamptz default now()

Table: menu_items
- id uuid PK default gen_random_uuid()
- category_id uuid FK → categories(id) on delete cascade
- name_bg text not null
- name_en text not null
- description_bg text
- description_en text
- price numeric(10,2) not null
- sort_number int default 0
- is_featured boolean default false
- image_url text
- created_at timestamptz default now()

## ADMIN PANEL at /admin
Design: light minimalist with warm accents (amber/warm tones), clean sidebar,
shadcn/ui components, good use of whitespace.

Password gate:
- Simple form at /admin/login
- Checks input against process.env.PASSWORD
- On success: set httpOnly cookie "admin_session=1" (via API route)
- Middleware protects /admin/* routes, redirects to /admin/login if no cookie

After login — sidebar layout with 2 pages:

### /admin/categories
- Table: image thumbnail, name_bg, name_en, sort_order, actions
- Add / Edit (modal or inline form): image upload (→ Cloudinary), 
  name_bg, name_en, sort_order
- Delete with confirmation
- Full CRUD via Supabase service_role client

### /admin/menu-items
- Table: image thumbnail, name_bg, category, price, sort_number, 
  is_featured badge, actions
- Filter by category (dropdown above table)
- Add / Edit (modal or inline form):
  image upload (→ Cloudinary),
  name_bg, name_en,
  description_bg, description_en,
  price,
  sort_number (hint: higher = shown first to customers),
  is_featured (checkbox),
  category (dropdown populated from categories table)
- Delete with confirmation
- Full CRUD via Supabase service_role client
